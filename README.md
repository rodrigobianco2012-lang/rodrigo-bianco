# Rodrigo Bianco — site oficial

Site estático em HTML/CSS, publicado com GitHub Pages.

## Publicação

O workflow em `.github/workflows/pages.yml` publica automaticamente o conteúdo da raiz do repositório no GitHub Pages quando há um push na branch `main` (ou quando o workflow é iniciado manualmente).

1. No GitHub, abra **Settings → Pages**.
2. Em **Build and deployment**, selecione **GitHub Actions** como fonte, caso ainda não esteja selecionada.
3. Aguarde a execução do workflow **Deploy static site to GitHub Pages** na aba **Actions**.

URL esperada: https://rodrigobianco2012-lang.github.io/rodrigo-bianco/

## Arquivos

- `index.html`: página principal.
- `.github/workflows/pages.yml`: workflow de deploy.

Antes de divulgar o site, confirme que os dados biográficos, links e perfis apresentados são oficiais e estão corretos.
